# Clustering & Embeddings Analysis

Repositório contendo análises, fundamentos e implementações de algoritmos de agrupamento (*clustering*) e análise de *embeddings* em Python.

## Estrutura do Repositório

```text
.
├── 01_Fundamentals.ipynb          # Conceitos fundamentais e pré-processamento para agrupamento
├── 02_K_Means.ipynb               # Algoritmo K-Means e variância intra-cluster
├── 03_Hierarchical.ipynb          # Agrupamento Hierárquico (Dendrogramas, Single/Complete Linkage)
├── 04_DBSCAN.ipynb                # DBSCAN (Agrupamento baseado em densidade e detecção de ruído)
├── 05_Clustering_Metrics.ipynb    # Métricas de avaliação (Silhouette Score, Davies-Bouldin, Calinski-Harabasz)
└── 10_Embeddings_Analysis.ipynb   # Análise, vetores e agrupamento em espaços de alta dimensão (Embeddings)

```

## Requisitos e Pré-requisitos

* **Python 3.8+**
* Jupyter Notebook / JupyterLab
* Bibliotecas principais: `scikit-learn`, `numpy`, `pandas`, `matplotlib`, `seaborn`
